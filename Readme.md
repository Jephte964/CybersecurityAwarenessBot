# Cybersecurity Awareness Bot

## Student Information
- Project: Part 1 POE
- Language: C#
- Application: Console App

## Features
- Voice greeting (WAV)
- ASCII cybersecurity logo
- Personalised user greeting
- Password safety tips
- Phishing awareness
- Safe browsing advice
- Input validation
- Typing effect and coloured console UI

## How to Run
1. Open the project in Visual Studio.
2. Build the solution.
3. Press Ctrl + F5 to run.
4. Ensure the Audio/greeting.wav file is included.
